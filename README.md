## Description

This project was initially built using static HTML and CSS.  
For Portfolio 1, the project was revisited and improved by adding dynamic functionality using JavaScript.

Improvements made:
- Replaced static product cards with dynamic rendering using the Noroff API
- Added loading and error states for better user feedback
- Implemented a dynamic product count using API metadata
- Made product cards fully clickable using semantic anchor elements
- Fixed GitHub Pages issues by updating asset paths to relative paths

## Built With

- HTML
- CSS
- JavaScript (Vanilla)
- Noroff Online Shop API
